LLM
會讀懂你的話、生出文字的 AI 大腦ChatGPT、Claude 背後都是它

LLM

是什麼

大型語言模型(Large Language Model)。用海量文字訓練、靠「預測下一個最合理的字」來生成回應的 AI。它不是資料庫、也不是搜尋引擎,而是一個會「接話」的機率引擎。

生活化比喻

像一個讀過幾乎整個網路的超級實習生你開個頭,他就能順著文意接下去寫但他是「憑印象」接,不是去查證。

真實場景

你在 ChatGPT 打「幫我把這段英文改得更正式」,背後運作的就是 LLM。

Generative AI
會「生出」新東西的 AI 總稱文字、圖片、影片、程式都算
點看細節 +
通用 AI 知識

Generative AI

是什麼

生成式 AI,指能產生「原本不存在的新內容」的一類 AI對比於只做分類、辨識的傳統 AI。LLM 是其中專做文字的一種,還有生圖(Midjourney)、生影片(Sora)等。

生活化比喻

傳統 AI 像「分揀員」(這是貓還是狗?);生成式 AI 像「創作者」(畫一隻沒人見過的貓)。

真實場景

請 AI 生一張簡報封面圖、寫一段行銷文案,都是生成式 AI 在做事。

Prompt
你打給 AI 的那段話、那個指令
點看細節 +
通用 AI 知識

Prompt

是什麼

提示詞,是你輸入給 AI 的指令或問題。同一個 AI,prompt 寫得清楚或模糊,結果天差地遠所以「怎麼問」本身是一種技能(今天第 4 章的 CCC 框架)。

生活化比喻

像點餐。只說「給我吃的」跟「我要一份不加洋蔥的中辣牛肉麵」,端上來的東西完全不同。

真實場景

「用三點摘要這份會議記錄,每點不超過 20 字」就是一個清楚的 prompt。

Token
AI 計算與收費的最小單位,大約一個詞或半個中文字
點看細節 +
通用 AI 知識

Token

是什麼

詞元。AI 不是一個字一個字看,而是把文字切成 token 來處理。英文約 4 個字母 ≈ 1 token,中文約 1 字 ≈ 1–2 token。用量計費、長度上限都以 token 計。

生活化比喻

像水電的「度」。用多少度付多少錢文章越長、對話越久,耗的 token 越多。

真實場景

API 帳單寫「本月用了 200 萬 tokens」,就是你輸入加 AI 輸出的文字總量。

Context Window
AI 一次能「同時記得」的內容上限
點看細節 +
通用 AI 知識

Context Window

是什麼

上下文視窗,是模型單次能讀取的 token 總量(輸入加輸出)。超過上限,最早的內容會被「遺忘」。視窗越大,越能一次塞進整份長文件。

生活化比喻

像桌面大小。桌子大,能同時攤開很多份文件對照;桌子小,放新的就得收走舊的。

真實場景

把一份 50 頁 PDF 整份丟給 AI 問問題,靠的就是夠大的 context window。

Tool
讓 AI 不只「動嘴」還能「動手」的外掛能力
點看細節 +
通用 AI 知識

Tool

是什麼

工具,是 AI 在對話之外能呼叫的實際功能:讀寫檔案、執行程式、搜尋網路、查資料庫。有了工具,AI 從「會講」變成「會做」。

生活化比喻

光有大腦只能想;給他手腳和一台電腦,他才能真的把事情辦完。

真實場景

Claude Code 幫你「讀這個資料夾、改好程式、跑測試」,每一步都是在用 tool。

MCP
讓 AI 接上各種外部工具與資料的「萬用插座標準」
點看細節 +
通用 AI 知識

MCP

是什麼

Model Context Protocol,一套開放標準,規定 AI 該怎麼跟外部工具/資料來源溝通。Anthropic 提出,現在 OpenAI、Google 也跟進採用,等於業界共通的「接線規格」。

生活化比喻

像 USB-C。以前每家插頭都不一樣,有了統一規格,任何裝置插上就能用。

真實場景

透過 MCP,Claude 可以直接連你的 Google Drive、資料庫或設計稿,不必你手動複製貼上。

RAG
讓 AI「先查資料再回答」,而不是純憑記憶
點看細節 +
通用 AI 知識

RAG

是什麼

檢索增強生成(Retrieval-Augmented Generation):回答前先從你指定的資料庫或文件撈出相關片段,連同問題一起餵給 AI,讓答案有依據、減少亂編。

生活化比喻

開卷考試。不靠死背,而是「先翻到對的那一頁,再照著回答」。

真實場景

公司客服機器人能精準答出「我們的退貨政策」,因為它先 RAG 撈了內部規章。

Agentic AI
一種讓 AI「自己規劃、自己動手、自己修正」的設計思路
點看細節 +
通用 AI 知識

Agentic AI

是什麼

代理式 AI,是一種設計範式,強調 AI 不只被動回答,而是能自行拆解目標、決定步驟、呼叫工具、檢查結果再調整。它描述的是「能力取向」,不是某個產品。

生活化比喻

差別在「給答案的顧問」與「直接幫你把事做完的助理」後者會自己安排先做什麼、後做什麼。

真實場景

你說「幫我訂下週去東京最便宜的機票」,它自己查、比價、下單這就是 agentic 的行為。

AI Agent
把上面那套自主能力做成的「實際程式」,Claude Code 就是一個
點看細節 +

AI Agent

是什麼

AI Agent 是 agentic 概念的具體載體:一個會循環「思考 → 用工具行動 → 觀察結果 → 再思考」直到完成任務的程式。它有 LLM 當大腦、工具當手腳。

生活化比喻

Agentic 是「自動駕駛」這個概念,AI Agent 就是「那台真的會自己開的車」。

真實場景

Claude Code 接到「把這個 bug 修好」,自己讀碼、改檔、跑測試、確認通過它就是個 AI Agent。

Hallucination

是什麼

幻覺,指 AI 生成了聽起來合理、實際上錯誤或虛構的內容(假的引用、不存在的數據、捏造的人名)。因為它是「預測最合理的字」而非「查證事實」,所以會自信地說錯。

生活化比喻

像一個很會講話的人,不懂裝懂也能說得頭頭是道你不查證就會被唬過去。

真實場景

你請 AI「給我三篇相關論文」,它列出格式完美、卻根本不存在的論文這就是幻覺,務必自己核實。

Claude

是什麼

Claude 是 Anthropic 推出的大型語言模型系列,以較強的推理與安全性著稱。依能力與成本分三級:Opus(最強)、Sonnet(均衡)、Haiku(最快最便宜)詳見第 2 章點開「LLM」層的對照。

生活化比喻

像汽車品牌底下的車款分級同品牌,但有旗艦、中階、入門,看需求選。

真實場景

寫複雜分析選 Opus,日常對話用 Sonnet,大量簡單分類用 Haiku。

Skill

是什麼

Skill 是把某個任務的步驟、規範、範例預先打包成模組;載入後 Claude 就照這套 SOP 執行,品質穩定、不必每次重教。

生活化比喻

像一張食譜卡。不必每次從頭教廚師,給他那張卡,他就能穩定做出同一道菜。

真實場景

載入一個「論文格式檢查」skill,之後每次丟文件進去,它都用同一套標準審。

Claude Code

是什麼

Claude Code 是一個以 Claude 為大腦的 AI Agent,在命令列(terminal)中執行。它能看你的專案、改檔案、跑指令,把「對話」變成「真的把事做完」今天整場用的就是它。

生活化比喻

ChatGPT 像隔著玻璃跟你聊的顧問;Claude Code 像走進你辦公室、直接坐下來幫你動手的同事。

第 4 章 · 25 min · 溝通框架

如何跟 AI 溝通,CCC 框架

大部分「AI 不行」其實是「我給的指令爛」三個字母解決大半科技管理者最重要的 AI 技能,跟最重要的非 AI 技能一樣,清楚地下達指令

Context
背景
任務、輸入、目標讀者、現有檔案,AI 需要知道你站在哪
點看細節 +
CCC 框架 · 第一個 C

Context背景

定義

告訴 AI 它需要知道的背景:任務是什麼、輸入是什麼、給誰看、有哪些現有檔案。AI 沒有讀心術你站在哪、要去哪,得講清楚,它才接得上。

生活上的使用情境

像跟新來的助理交辦。你不會只說「處理一下」,而會說「這是客戶名單、要寄活動邀請、對象是 VIP、用公司信頭」對方才做得對。

Constraints
限制
格式、長度、能/不能做什麼、依賴條件,AI 需要知道邊界在哪
點看細節 +
CCC 框架 · 第二個 C

Constraints限制

定義

告訴 AI 邊界:輸出格式、長度、能做什麼不能做什麼、要遵守的依賴條件。沒有邊界,AI 會自由發揮到你不要的方向。

生活上的使用情境

像找設計師裝潢。只說「弄好看」會得到你不想要的風格;說「北歐風、預算 10 萬、不能動牆」才會收斂到對的結果。

Check
驗證
AI 給的我有沒有當真?有沒有抽查?採納還是丟掉?,這是你最不能外包的事
點看細節 +
CCC 框架 · 第三個 C

Check驗證

定義

AI 給的東西,你有沒有當真?有沒有抽查、核對來源?最後採納還是丟掉?這一步是你最不能外包的責任尤其面對「幻覺」。

生活上的使用情境

像實習生交報告。你不會直接簽名上呈,會先抽幾個數字核對、確認沒亂編,才掛上自己的名字。

會議筆記
Bad,請你猜
幫我整理一下會議筆記
Good,請你做

課前準備 · 新手必看

課前準備 + 新手操作小抄

上課 90% 的卡關都來自下面這幾件「操作」小事先看過,當天會順很多看不懂沒關係,先做能做的,卡住就標記是哪一步,當天直接問

一 · 課前 30 分鐘 checklist
  • 下載並安裝 Cursor(選對應你系統的版本)
  • 用 Google 或 GitHub 登入 Cursor(選免費方案,不要選 Pro)
  • 註冊一個 GitHub 帳號
  • 下載今天會用到的三份檔案:setup.md / panel-setup.md / github-setup.md
  • 確認可以分享螢幕(Google Meet / Zoom 先測一次)
二 · 操作小抄(最常卡的 7 件事)
⚠️ Cursor 登入:選「免費」,不要選 Pro
看到「Pro plan / Upgrade / $20/month」先不要點,今天用免費就夠。看到要刷卡＝你點到付費了,退回上一頁重選。
1切換視窗(最常迷路)
Mac:四/五指往上滑看所有視窗,或 Cmd + Tab 切 App,或點下方 Dock。分不清「Cursor 桌面 App」和「瀏覽器網頁」我們要用的是桌面 App。
2分享「整個螢幕」,不要分享單一視窗
選 整個螢幕（Entire Screen）。不要中途按「停止共享」切視窗時畫面會自己跟著換。
3複製貼上:確認前後沒有多餘空格
最常見的失敗。從網頁複製指令貼上時常黏到空格或半個字,導致它「認不出檔案/指令」。貼上後檢查開頭結尾乾不乾淨,不確定就刪掉重貼失敗時 80% 是這個。
4Claude Code 只能用鍵盤,不能用滑鼠點
選項用 ↑↓ 移動、Enter 確認;取消按 Esc(連按兩次回上一步);換行不送出 Shift + Enter。滑鼠點不動是正常的。
5@ 引用檔案(口語「小老鼠」)
@ 後面緊接檔名,前後不要黏字或空格;打幾個字會自動跳出補全,用方向鍵選、Enter 帶入。
6Slash 指令 /... 貼進「Claude Code 輸入框」
像 /plugin install ...、/claude-hud:setup 這種斜線指令,貼到 Claude Code 的輸入框(不是 Mac 終端機、也不是 Cursor 聊天框),一行一行貼、一行一行 Enter。
卡關自救三步:① 先用白話問 Claude/Cursor 本人「我卡在 X、畫面顯示 Y,怎麼辦?」② 逐行讀它的回覆 ③ 真的不行,記下「卡在哪一步、畫面顯示什麼」當天問講師。笨問題都可以問。
課後 FAQ

常見問題 Q & A

整理自課堂上同學問過的問題給上完課想再確認、或當天沒問到的人

Q1我不是工程師(PM / Data Scientist / 學生),需要用 GitHub 嗎?
需要、而且很值得。GitHub 是你成果的雲端備份 + 版本歷史 + 分享連結。連上 Claude Code 後,你可以用自然語言叫它幫你推檔案、或從 GitHub 抓東西,不必自己點網站。
Q2各家 LLM(Claude / GPT / Gemini / DeepSeek)差在哪?只有 context window 不同嗎?
不只。它們在推理能力、訓練資料、強項、速度、價格都有差,context window 只是其中一個維度。選法:難任務用最強(Opus 級)、日常用均衡(Sonnet 級)、大量簡單任務用最便宜(Haiku 級)。
Q3CLAUDE.md 和 MEMORY.md 差在哪?
CLAUDE.md＝你寫給 AI 的「專案說明書」,每次自動讀,是 Claude Code 原生的記憶機制。「跨對話自動記住你習慣」屬進階用法,通常要搭配記憶外掛(如 claude-mem),不是內建。初學先會用 CLAUDE.md 就夠。
Q4不同 session(對話)之間怎麼共享進度?
不是靠某個檔案自動同步。常見做法:叫舊 session 把進度「寫成一份交接檔(handoff)」,新 session 再讀;或把重點寫進 CLAUDE.md。
Q5/compact 是什麼?有什麼代價?
對話太長時,/compact 把對話壓縮成摘要釋放空間。代價是去脈絡化細節可能遺失。建議 context 到 ~70% 時做,或改用「寫交接檔 + 開新 session」。
Q6MCP 是什麼?是各工具自己做、還是 Claude Code 做?
MCP 是 Anthropic 提出的協定/標準(像 AI 版的 USB-C),規定 AI 怎麼接外部工具。各家(GitHub、Figma)依這標準做自己的 MCP server所以是「各工具自己做、遵守同一套規格」。
Q7某個工具還沒有 MCP,就沒辦法用了嗎?
不會。Claude Code 還能用 Playwright 這類工具直接開網頁、模擬點選來操作沒 MCP 的服務(只是慢、陽春一點)。
Q8用中文還是英文跟 AI 溝通比較好?中文比較耗 token 嗎?
中文 token 確實略多,但差距很小、不影響到要在意。重點是「哪種語言更能把問題講清楚」清楚表達 > 省 token。用中文完全 OK(連 skill 都能用中文寫)。
Q9Skill 該做多大才合適?
Skill 是高層的工作流程 SOP(步驟+規範+範例,可附腳本),不是單一小函式。判準:會重複用、有固定步驟的流程適合;一整個獨立系統就做成 project。不確定就問 Claude「這適合做成 skill 還是 project?」
Q10中途換模型,會把前面的對話清掉嗎?
不會,對話內容還在。只是會讓快取(cache)失效,下一輪稍微變貴、變慢。真的要換,建議開新 session 比較乾淨。
Q11Cursor 登入看到「Pro / $20」是不是會被收費?
那是付費方案。今天用免費就夠,不要點 Pro / Upgrade。不小心點到(要刷卡)就退回上一頁重選免費。
Q12我裝環境一直卡關怎麼辦?
先看上方課前準備的操作小抄(90% 卡關是:視窗切換、複製帶到空格、Claude Code 只能鍵盤、@ 引用)。再不行,直接用白話問 Claude 本人,或記下卡在哪一步問講師。
