● 第 2 章 · 三層架構 · 10 min

你會遇到的三個層級

公司說「我們要投資 AI」是哪一層?
不同層、不同價、不同槓桿——簽約前先學會分辨。

⏱ 10 分 · 開場 🪝 Hook：「以後有人跟你說『我們公司要投資 AI』，你要會反問一句：**你說的是哪一層？**——因為三層的價錢和槓桿差很多。」 → 接下一頁：把三層攤開來看。
● LLM → Product → Agent

由下往上,愈上層愈具體

🎤 口述（由下往上，配合 fragment 一層一層出）： - 最底層 **Model（LLM）**＝那顆大腦，會生成。 - 第二層 **Product**＝把大腦包成聊天 App（ChatGPT），很強但**只活在對話框裡**，看不到你的檔案、不能動手。 - 第三層 **Agent**＝像 Claude Code，會看檔、改檔、跑指令，把「對話」變成「交付」。 🔑 LLM 會生成｜Product 會聊天（困在框裡）｜Agent 會動手（交付） → 接下一頁：用「分析 100 份問卷」讓他們有感。

Agent · Claude Code

  1. ✓ 直接讀 survey.csv

  3. ✓ 圖表自動輸出到 charts/
10 分鐘 → 完整初稿
🎤 口述：「用 ChatGPT，你得一筆筆貼、它告訴你怎麼做、你再自己去 Excel 跑，30 分鐘還是半成品。用 Agent，它直接讀你的 survey.csv、自己寫 Python 跑、圖表自動輸出，10 分鐘給你完整初稿。」 🌰 比喻：Product 像隔著玻璃跟你聊的顧問；Agent 像走進辦公室、坐下來幫你做的同事。 → 接最後一頁的收尾金句。
