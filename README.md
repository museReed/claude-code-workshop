# Claude Code Workshop

AI Agent 初階 Workshop 教材——帶非工程背景的學員從「跟 AI 聊天」走到「指揮 AI 做事」。

**Slides**：https://musereed.github.io/claude-code-workshop/slides.html

## 內容

| 檔案 | 用途 |
|---|---|
| `slides.html` | 完整投影片（上下半堂，S01–S70，GitHub Pages 部署） |
| `exercises/` | 四大實作情境素材：學術研究 / 會議記錄 / 倫敦找房 / 求職 |
| `setup.md` / `github-setup.md` / `panel-setup.md` | 環境安裝指南（餵給 AI agent 執行） |
| `onboarding.md` / `faq.md` | 學員入門與常見問題 |
| `teacher-runbook.md` | 講師手冊 |

## Workshop Repo 地圖

| Repo | 用途 |
|---|---|
| 本 repo | 教材本體 + slides |
| [jr_ai_agent_configs](https://github.com/museReed/jr_ai_agent_configs) | 規則檔安裝包：CLAUDE.md / AGENTS.md / output-style（zh-TW·zh-CN·en） |
| [jr_ai_agent_skills](https://github.com/museReed/jr_ai_agent_skills) | 三個 skill 安裝包：structured-questions / auto-rename / handoff |
| [claude-code-workshop-jr-student](https://github.com/museReed/claude-code-workshop-jr-student) | 學員版素材 |

學員安裝方式：把上面安裝包 repo 的 README 指示貼給你的 AI agent 即可。
