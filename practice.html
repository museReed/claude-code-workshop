實戰篇：動手做

接下來 3 小時，你會從零搭建一個 Claude Code 環境，完成真實場景的練習，最後把成果推上 GitHub。

P1 — 40 min

環境安裝

跟著下面 6 步走，裝好你的 Claude Code 開發環境。

  • What：Cursor 是一個內建 AI 功能的程式編輯器（像 Word，但是給程式碼用的）。

    How：到 cursor.com 下載，拖進應用程式資料夾。

    Verify：打開 Cursor，看到歡迎畫面就成功了。

  • What：Node.js 是讓 Claude Code 能跑起來的基礎環境（像電要先通才能開燈）。

    How：打開 Cursor 的 terminal（快捷鍵：Ctrl+`），輸入：

    curl -fsSL https://fnm.vercel.app/install | bash

    然後重新開 terminal，輸入：

    fnm install --lts

    Verify：輸入 node --version，看到版本號就成功了。

  • How：在 terminal 輸入：

    curl -fsSL https://claude.ai/install.sh | bash

    Verify：輸入 claude --version，看到版本號就成功了。

  • What：API Key 是你的「通行證」，讓 Claude Code 知道你是誰。

    How：

    1. 到 console.anthropic.com 註冊／登入
    2. 建立一個 API Key
    3. 在 terminal 輸入 claude 啟動，第一次會問你登入方式
    4. 選擇 API Key，貼上你的 key

    API Key 要保密！不要截圖分享、不要貼到聊天群組。就像你的銀行密碼一樣。

  • How：建立一個練習資料夾：

    mkdir ~/workshop && cd ~/workshop
claude

    看到 Claude Code 的歡迎訊息就成功了！

  • 輸入 /model 選擇模型（建議用 Sonnet，便宜又快）。

    輸入 /permissions 了解權限設定。

卡住了？

  • 卡在 Node.js 安裝？ → 試試直接到 nodejs.org 下載安裝檔。
  • Claude Code 安裝失敗？ → 確認 terminal 有網路連線，試 ping google.com。
  • API Key 不 work？ → 確認 key 沒有多餘的空白，重新複製貼上一次。

P2 — 15 min

第一次對話

確認環境能跑，感受 Agent 跟 ChatGPT 的差別。

  1. 確認你在 ~/workshop 資料夾
  2. 跟 Claude Code 說： 
    你好，請幫我建立一個 hello.md 檔案，內容寫上我的名字和今天的日期
  3. 觀察 Claude Code 做了什麼 — 它會讀你的指令、建立檔案、告訴你它做了什麼
  4. 打開 Cursor 的檔案瀏覽器，確認 hello.md 出現了

Key Learning

注意！你沒有寫任何程式碼。你只是用中文說了你要什麼，Claude Code 就幫你做了。這就是 Agent 跟 ChatGPT 的差別。

P3 — 20 min

安裝 4 個 Skill

Skills 是 Claude Code 的「外掛」，讓它多學一些本領。

Skill 1：HUD（狀態列）

安裝指令：

claude plugin add claude-hud

安裝後輸入 /claude-hud:setup 設定。

效果：terminal 底部會出現一個狀態列，顯示 model、token 用量、session 名稱。

Skill 2：auto-rename

已內建，不需安裝。

功能：每次對話結束會自動取一個有意義的名字。

Demo：開一個新對話，做點事情，然後看 session 名稱自動更新。

Skill 3：structured-question

Claude 要問你問題時，會列出選項讓你選，不用自己打字回答。

已內建 skill，在 CLAUDE.md 裡啟用 — 加上：

## 溝通方式
- 遇到需要我做決定的時候，用 structured-question 技能列出選項讓我選

Skill 4：handoff（交接）

工作做到一半要結束 session 時，自動產生交接文件，下次開新 session 可以接著做。

已內建 skill。

Demo：在對話中輸入 /handoff，看它產生什麼。

P4 — 20 min

寫你的 CLAUDE.md

現在你要寫自己的 CLAUDE.md — 給 Claude Code 的「員工手冊」。

  1. 在 Claude Code 裡說：「請幫我建立一個 CLAUDE.md 檔案」
  2. Claude 會問你一些問題（用 structured-question！）
  3. 或者，直接用下面的模板開始：
# [你的專案名稱]

## 關於我
[你是誰？什麼科系？研究什麼？]

## 語言
- 用繁體中文回答
- 技術名詞保留英文

## 規則
- [你的特定規則，例如：學術內容必須附出處]
- [例如：不要編造引用或數據]

## 偏好
- [你喜歡怎麼收到回覆？簡短 or 詳細？]
- [你的檔案命名習慣？]

練習

花 10 分鐘填寫你自己的版本，然後用 Claude Code 幫你 polish。CLAUDE.md 會越用越好 — 它是你跟 AI 之間的長期默契。

P5 — 30 min

情境練習：學術場景

選一個你有興趣的學術任務，用 Claude Code 完成它。

Option A

文獻整理矩陣

建立一個 literature-matrix.md。

Prompt 範例：

幫我建立一個文獻整理矩陣 literature-matrix.md。我的研究主題是 [你的主題]。矩陣的欄位：作者/年份、研究方法、主要發現、跟我研究的關聯、我的評論。先建好表格結構，我會自己填入資料。

Option B

論文大綱

建立 dissertation-outline.md。

Prompt 範例：

幫我建立一份論文大綱 dissertation-outline.md。我的題目是 [你的題目]。列出建議的章節結構（Introduction、Literature Review、Methodology、Findings、Discussion、Conclusion），每個章節下列出 3-5 個你建議討論的子題。這是建議，我會自己修改。

Academic Integrity 學術誠信

Claude 可以幫你建表格結構和論文大綱，但不可以幫你寫 critical analysis。表格裡的「我的評論」欄位，你必須自己填。

Claude 建議的結構是起點，不是終點。你必須根據你自己的研究問題和導師的指導來調整。

P6 — 30 min

情境練習：生活／職涯場景

選一個跟你生活相關的任務來練習。

Option A

倫敦租屋比較表

建立 housing-comparison.md。

Prompt 範例：

幫我建一個租屋比較表 housing-comparison.md。我在看以下幾間房：[描述 3-5 間房的資訊]。欄位：地址、月租（£）、含/不含 bills、距離 KCL Strand 通勤時間、房型、優點、缺點。按月租排序。

Option B

履歷客製化

建立 tailored-resume.md。

Prompt 範例：

讀 resume.md 和 job-description.txt。根據 JD 裡要求的技能和經驗，調整我的履歷 bullet points，讓每條都盡量對應到 JD 的要求。不要編造經歷。完成後做一個「覆蓋率表」列出：JD 要求 → 我的對應經歷 → 匹配程度（高/中/低）。

提醒

不要讓 Claude 編造你沒有的經歷或技能。它可以幫你重新措辭，但內容必須是真的。

P7 — 15 min

推上 GitHub

把今天的成果上架到你的 GitHub，變成你的「AI 技能證明」。

  1. 在 terminal 確認你在 ~/workshop 資料夾
  2. 初始化 git repo： 
    git init
git add .
git commit -m "My first Claude Code workshop output"
  3. 在 GitHub 建立一個新 repo（名字建議：claude-code-workshop-output）
  4. 連結並推上去： 
    git remote add origin https://github.com/YOUR_USERNAME/claude-code-workshop-output.git
git push -u origin main
  5. 打開 GitHub 確認你的檔案出現了

恭喜！你現在有了一個 GitHub 上的作品。這是你的「AI 技能證明」— 未來面試時可以分享。
