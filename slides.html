第六章 · 進階觀念

設定分兩層

只要記住：一個跟著「你」走，一個跟著「專案」走。

User Level

跟著你這個人

~/.claude/
  • 所有專案都會套用
  • 適合個人偏好、語氣、工作習慣
  • 只在你的電腦上生效
Project Level

跟著這個專案

專案資料夾/.claude/
  • 只在這個專案內生效
  • 適合團隊規範、專案規則
  • 可以跟 repo 一起共享
選擇原則：個人習慣放 User Level；專案或團隊規則放 Project Level。兩邊衝突時，Project Level 優先。

進階 · 讓 Agent 自己動手

讓 AI 不用每次都問你

預設每個動作都要你按一次「同意」。上手後，可以「授權」AI 在安全範圍內自動執行，你只看結果——快很多，但要先分清楚哪些能放手。

全手動

每一步都問你。最安全，但一直被打斷。

半自動 ★

安全的事自動做，危險的事才停下來問。今天的甜蜜點。

全自動

什麼都不問。最快也最危險，留給拋棄式環境。

白名單的常見雷

加了白名單，為什麼還是問我？

現象：你明明把 git status 加了白名單，AI 一跑 git status && npm test 又跳出來問。

原因（一句話）：AI 會把 &&、|、; 這種「一行串多個指令」拆開逐一檢查——只要其中任何一個沒在白名單，整串就停下來問你。npm test 沒加，所以就算 git status 是信任的，還是被卡住。

解法 ① ★ 最推薦
拆成一條一條跑

「一條指令做一件事」，不要串 &&。每條都能對上白名單，最穩。

解法 ②
把每個子指令都加

串裡用到的每一個都放進白名單，例如再加 Bash(npm test:*)。

解法 ③
用更寬的規則

整組放行，如 Bash(git *)、Bash(npm *)。方便但信任範圍變大。

✓ 優先選 ① ——就是我們一直在講的「一條指令一件事」，白名單命中率最高，也最容易看懂 AI 每一步在做什麼。

貼上 Prompt，建立 CV-JD Tailoring Skill

你只要回答白話問題，AI 會把答案轉成設定，自己去呼叫 skill-creator。

貼進 Claude Code 
我想做一個 skill，之後每次投履歷都用它：讀我的 CV 和一份 JD，
拆 JD 的要求、對照我的經歷找缺口、把能寫得更好的地方改寫。

請先用 structured-questions 問我幾個白話問題。
我不懂 skill-creator 的設定，所以不要問我技術參數——
問我「這個 skill 要叫什麼」「產出想要幾份檔案」
「哪些情況要停下來問我」這種我答得出來的問題。

我回答完之後，你把我的答案轉成 skill-creator 需要的設定，
自己去呼叫 skill-creator 把 skill 建出來，不用再問我一次。

這個 skill 要做的事：
1. 拆 JD：分成 Required（沒有就不進面試）、Preferred（加分）、
   Implicit（沒明說但面試官在看）三層，每層一張 table。
2. 對照 CV：每條要求標 ✅ 有具體經歷 / ⚠️ 有但寫太弱 / ❌ 完全沒有；
   出現「幫忙 / 參與 / 協助」這種詞的一律算 ⚠️。
3. 改寫：只改真實經歷撐得住的 bullet，改成「動作 + 數字 + 結果」；
   沒有數字的地方寫 [數字待確認]。
4. 最重要：不可以編造任何我 CV 裡沒有的工作、數字或成就。

MCP · Playwright — 讓 AI 長眼睛

Playwright MCP 能做什麼

MCP 是什麼？
把 MCP 想成 AI 的「工具插座」：它用同一套方式連接外部工具與資料。Playwright MCP 就是讓 AI 能開瀏覽器、看網頁並操作網頁的工具。
📋 一般場景
▸ 打開網頁、截圖給你看
▸ 自動填表單、點按鈕
▸ 抓頁面文字 / 表格資料
▸ 檢查連結、流程走一遍
💻 Coding 場景
▸ 網頁做完自我驗證畫面
▸ RWD 各尺寸截圖比對
▸ E2E 測試（自動點到底）
▸ 抓 console error 回報
⚡ 使用方式
裝好後直接說「打開這個網頁截圖給我看」，AI 自動用 Playwright
✓ 適合
✗ 不適合
要 AI 看到 / 操作真實網頁
純文字任務、不用開瀏覽器
網頁做完自我檢查、截圖
大規模爬蟲 scraping（另有工具）
E2E 測試、表單流程驗證
需登入且有 2FA 的複雜流程

進階 · Remote Control

人不在電腦前，也能繼續

電腦繼續做事，手機只是一個窗口。

跑的還是你的電腦

檔案、專案設定、MCP 都在原本那台。手機沒有跑任何東西。

手機做的是「回話」

看進度、回答它的問題、按批准——它接著剛才的進度繼續做。

不用開對外的埠

連線由你的電腦主動發起，全程你這邊說了算。

📱 最適合的場合：剛才那種要跑好幾分鐘的任務——交代完就可以走開，用手機看它跑完。

⚠️ 這一頁是重點

兩邊不是同一件事

指令幾乎一樣，但接上去的東西不一樣。拿 Codex 想接管剛才終端裡那個 session，會找不到。

Claude Code
claude remote-control
  • 接上正在跑的那個 session
  • 用 claude.ai/code 或 Claude App
  • 掃 QR，或開它給的 session 網址
Codex
codex remote-control
  • 需要 CLI 0.130 以上
  • 另開一個專屬遠端的 session
  • 用 ChatGPT App 的 Remote，選裝置
  • 接不了你已經在終端跑的那個
! 電腦睡著就斷了——要嘛設不睡眠、要嘛接電源。還有：手機上按的「同意」跟坐在電腦前按的是同一件事，別在通勤時隨手按。

現場做一次 · Claude Code

實際接一次給你看

Codex 流程一樣，差別是從 ChatGPT App 選裝置，而且是新開一個 session。

01 · 在電腦上開

按空白鍵可以切換 QR 顯示。

03 · 接上之後

電腦那邊照樣在跑，手機看得到同一段輸出。

04 · 回答它的問題

要批准的動作，在手機上按同意就好。

▶ 練習：叫它做一件要跑幾分鐘的事 → 開 remote control、手機接上 → 闔上筆電（不要關機）→ 在手機上追加一句要求，看電腦那邊有沒有照做。
