第 3 章 · 40–55 min · 安裝

安裝與第一次對話，讓 AI(Cursor) 安裝 AI(Claude Code)

你手動的部分很少——裝一個 Cursor、註冊一個 GitHub。剩下讓 AI 讀 setup.md 代勞：Node.js、Claude Code、API key、狀態列面板、GitHub repo。
安裝本身就是第一堂課。

Permission Model

Cursor 和 Claude Code 都會問 Allow?——AI 再聰明，人類始終在控制迴圈中
你按 Allow 才會跑，不按它就停。這是 AI Agent 跟 ChatGPT 最大的差別之一
