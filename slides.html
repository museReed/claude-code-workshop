第 4 章 · 25 min · Prompt 技巧

如何讓 AI 做對事
Anthropic 官方 Prompt 原則

大部分「AI 不行」其實是「我說的不夠清楚」

今天你跑的每個場景——學術研究、求職、倫敦租房——
都能套用同一套 Claude 官方的 Prompt 原則

Anthropic Golden Rule

把 Prompt 當工作交辦清單

「把 Claude 想像成一個剛入職、但很聰明的新同事，他不懂你的 workflows 和習慣。
你說的越清楚，他做的越準。」

— Anthropic 官方 Prompt Engineering Docs

Self-check：把你的 Prompt 給一個對任務沒有背景的同事看——如果他看完不知道要做什麼，Claude 也會做錯 ✗

Be Clear & Direct

03

「你是一位...」定義口吻能力

04

給範例

展示比說明更有效，給 3–5 個

05

指定格式

說清楚格式、長度、結構

01

清楚直接 · Be Clear & Direct

說清楚你要什麼結果、格式、長度，不讓 AI 猜

✗ Bad — AI 會自由發揮

幫我寫一份報告

✓ Good — 明確說出期望

讀 sales_data.xlsx（Q2 銷售數據），寫一份給 CEO 看的月報，包含：業績摘要、三個關鍵洞察、下一季建議行動，每點不超過 30 字

02

解釋為什麼 · Add Context

說明背景和理由，Claude 會從中推斷更多你沒說的需求

✗ Bad — 只給規則沒給理由

不要用被動語態

✓ Good — 說明為什麼

這篇文章要發 IG，受眾是 25 歲年輕人，所以不要用被動語態——聽起來太正式，他們習慣口語化的表達方式

03

給 AI 一個角色

Give a Role

在 Prompt 開頭設定角色，Claude 的口吻、專業判斷、措辭方式都會跟著調整到位。

✓ 範例

你是一位專精台灣學生在英國租屋的法律顧問，熟悉 UK tenancy law...

04

給範例

Use Examples

展示比說明更有效。給 3–5 個好例子，讓 Claude 對齊你的風格和標準，而不是用文字描述。

Anthropic 建議：用 <example> tags 把範例包起來，讓 Claude 能區分「範例」和「指令」，不會混淆

05

指定格式

Specify Format

明確說出輸出格式、長度、結構，否則 AI 會自由發揮到你不要的方向。

✗ 寫一份摘要

✓ 條列 3 個重點，每點 ≤20 字，最後一行給一個可執行的行動建議

設定裝哪裡？ 兩個層級

Claude Code 的設定分兩層——搞清楚差別，後面裝 CLAUDE.md 和 Skill 就不會亂。

User Level
~/.claude/
  • 跟著你這個人走
  • 所有專案都會套用
  • 個人偏好、習慣、風格
  • 只在你的電腦上生效
🌰 像你手機的系統設定——換哪個 App 都生效
Project Level
你的專案/.claude/
  • 跟著這個專案走
  • 只在這個資料夾內生效
  • 專案規範、團隊規則
  • 推上 Git → 全組共用
🌰 像某個 App 自己的設定——只在那個 App 裡生效

實作 · 開始動手

▶ Step 01 · 釐清需求 — 先讓 AI 問你

我想做一個叫 academic_chapter_draft 的 skill。它的功能是：給定 2-5 篇學術素材（論文 PDF、課堂筆記、書籍章節），自動跑完一條 pipeline：

Step 1: 逐篇摘要（每篇 200 字以內）
Step 2: 萃取各篇核心論點，標記共識與分歧
Step 3: 產出交叉比較矩陣
Step 4: 撰寫一個章節的學術初稿（含引用標記）

請用 /structured-questions 向我確認你需要知道的細節，例如：學科領域、引用格式、章節結構偏好、初稿長度等。

⚡ Step 02 · 捷徑 — 一句話串起 Step 01 + 03

使用 /structured-questions 引導我使用 /skill-creator

（AI 自動先問再建，不需要分兩次下指令。用這句可以跳過手動貼 Step 01 + 03。）

▶ Step 03 · 建立 Skill — 回答完問題後貼入

根據我剛才回答的所有偏好，用 /skill-creator 的 Create 模式，幫我建立 academic_chapter_draft skill。
Skill 要包含完整的 4 步驟 pipeline，並把我的偏好寫進 SKILL.md。

▶ Step 04 · 測試 + 使用 — Skill 建好後

CC：/academic_chapter_draft
Codex：$academic_chapter_draft

用你手邊的素材跑一次，看產出是否符合你的預期。不滿意就告訴 AI 哪裡要調整。

💡 沒有素材？
跟 AI 說「幫我找 3 篇關於 [你的領域] 的摘要當素材」，先用假資料跑通 pipeline，之後再換真的。
🔄 不滿意怎麼辦？
跟 AI 說「用 /skill-creator 的 Improve 模式，我覺得引用格式不對」。AI 會讀你的回饋自動改 SKILL.md。
